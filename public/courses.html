FAQ

Questions, answered

Do I need to know how to code?
Not for AI Training Foundations — it’s designed for complete beginners. For Agent Building and Website Building, we start from zero code and ramp up fast. If you can use a spreadsheet, you can start here.
What tools will I learn?
ChatGPT, Claude, Gemini and Llama for foundations; LangChain, n8n, the OpenAI SDK and MCP for agents; JavaScript, React/Next.js, Node.js, Express, SQLite/Postgres for websites — plus Cursor for AI-assisted development.
How much time per week?
Plan for 5–7 hours: one live session (~90 min), one project build, and short daily lessons. Every module is recorded if you miss a live session.
Is the prompt library really free?
Yes — all 2,900+ prompts in our library are free forever, powered by the open-source prompts.chat dataset (CC0). No account, no paywall.
What does deployment cost after the website program?
₹0 to start. We teach free tiers end-to-end: Vercel or Render for hosting, Neon or Supabase for Postgres, and free subdomains — with clear paths to custom domains when you outgrow them.
Do you help with jobs after?
The Expert Track includes a portfolio review, interview prep and referrals through our hiring partner network. Alumni regularly land AI automation, prompt engineering and junior full-stack roles.
